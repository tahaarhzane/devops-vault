# DevOps Vault

Base de connaissances personnelle, organisée par domaine. Chaque note suit le même format :
`_templates/template-note.md` (Contexte / Notes / Références).

## Domaines

- [Kubernetes](Kubernetes/README.md) — le plus fourni : architecture, workloads, réseau,
  stockage, scheduling, observabilité, opérations
- [Concepts transverses](Concepts%20transverses/README.md) — notions qui recoupent plusieurs
  domaines (RBAC, Ingress, service mesh...)
- [Réseau & sécurité](Réseau%20%26%20sécurité/README.md) — DNS, load balancing, firewalling,
  hardening
- [Azure](Azure/README.md) — services, architecture, IAM
- [OpenShift](OpenShift/README.md) — spécificités vs Kubernetes vanilla, opérateurs, routes
- [Git & CI-CD](Git%20%26%20CI-CD/README.md) — Git, GitOps, pipelines CI/CD

Chaque dossier a son propre `README.md` qui sert de sommaire pour ce domaine.
